# V2RayPort

`V2RayPort` — это базовый desktop-порт идеи мобильного клиента **V2RayTun** для ПК.

Сейчас в репозитории реализован MVP:
- графический интерфейс на `tkinter`;
- выбор пути к `v2ray`/`xray` бинарнику;
- выбор JSON-конфига;
- запуск и остановка процесса ядра;
- просмотр логов в реальном времени.

## Быстрый старт

1. Установите Python 3.10+.
2. Подготовьте бинарник `v2ray` или `xray`.
3. Подготовьте рабочий JSON-конфиг.
4. Запустите:

```bash
python3 v2rayport.py
```

## Что важно понимать

- Это **не полноценный клон V2RayTun**, а стартовая desktop-заготовка.
- Системный VPN/TUN-режим в этом MVP не реализован.
- Для полноценного порта дальше обычно добавляют:
  - профили/подписки;
  - режимы маршрутизации;
  - системный прокси;
  - автозапуск и трей;
  - установщики для Windows/macOS/Linux.

## Структура

- `v2rayport.py` — основной desktop-клиент (MVP).
